GSEA Null Calibration: Permutation vs Rotation (Walkthrough)

Portfolio

1 Overview

This document explains the main steps in rotations.r, runs the simulation script, and summarizes the differences between gene-wise permutation and rotation-based null generation.

The report is designed to rerun quickly:

  • rotations.r now uses a simulation cache (simulation_cache.rds) for Monte Carlo outputs
  • this Quarto document also enables knitr chunk caching

If the cache does not exist (or configuration changes), the first run can still take a while.

2 What rotations.r Does (Step-by-Step)

2.1 1. Configuration

The script sets:

  • dataset dimensions (ngenes, nsamples)
  • gene set size (set_size, set_idx)
  • Monte Carlo settings (nsim, nperm, nrot)
  • correlation settings (rho_set_grid, rho_bg)
  • parallelization mode (parallel_over, ncores)
  • cache options (use_simulation_cache, simulation_cache_file)

2.2 2. Core helper functions

The script defines functions to:

  • compute a GSEA-like enrichment score (gsea_set_stat)
  • compute empirical right-tail p-values (empirical_p_right)
  • simulate correlated noise in set and background genes
  • simulate null datasets (no differential expression)
  • fit limma and compute enrichment scores from p-values
  • build a rotation basis from the null-model residual space
  • sample random orthogonal rotations in that residual space

2.3 3. Null generation methods compared

For each simulated dataset, the script computes:

  • Permutation null: shuffles gene-wise p-values before recomputing the set statistic
  • Rotation null: rotates residuals under the null model, refits, and recomputes the set statistic

This is repeated over:

  • multiple correlation strengths in rho_set_grid
  • multiple Monte Carlo replicates (nsim)

2.4 4. Summaries and output files

The script then:

  • summarizes empirical type-I error and mean p-values by rho_set
  • writes CSV outputs
  • creates diagnostic plots (calibration panel, ECDF, null histograms)
  • creates correlation heatmaps and rotation-preservation diagnostics

7.3 6. Inline correlation-preservation visualization (original vs rotated)

The next chunk recreates the key idea visually for the lowest and highest rho_set example datasets:

  • original gene-gene correlation heatmap
  • rotated gene-gene correlation heatmap
  • scatter of pairwise correlations (original vs rotated)
plot_rotation_preservation_inline <- function(Y, set_idx, rho_val, bg_n = 300) {
  if (is.null(Y)) {
    plot.new()
    title(sprintf("rho_set = %.1f", rho_val))
    text(0.5, 0.5, "Example dataset not available")
    return(invisible(NULL))
  }

  nsamp <- ncol(Y)
  design0 <- matrix(1, nrow = nsamp, ncol = 1)
  fit0 <- limma::lmFit(Y, design0)
  Yhat0 <- fitted(fit0)
  res0 <- Y - Yhat0
  basis <- build_rotation_basis(design0 = design0, nsamples = nsamp)
  Rmat <- sample_rotation_matrix(basis)
  Y_rot <- Yhat0 + res0 %*% Rmat

  bg_idx <- setdiff(seq_len(nrow(Y)), set_idx)
  if (length(bg_idx) > bg_n) bg_idx <- sample(bg_idx, bg_n)
  keep_idx <- c(set_idx, bg_idx)

  corr_orig <- cor(t(Y[keep_idx, , drop = FALSE]))
  corr_rot <- cor(t(Y_rot[keep_idx, , drop = FALSE]))
  u <- upper.tri(corr_orig)
  x <- corr_orig[u]
  y <- corr_rot[u]
  r_xy <- suppressWarnings(cor(x, y, use = "complete.obs"))
  mad_xy <- mean(abs(x - y), na.rm = TRUE)

  cols <- colorRampPalette(c("#313695", "#ffffbf", "#a50026"))(100)

  image(
    seq_len(nrow(corr_orig)), seq_len(ncol(corr_orig)),
    corr_orig[nrow(corr_orig):1, ],
    col = cols, zlim = c(-1, 1), axes = FALSE,
    xlab = "Genes", ylab = "Genes",
    main = sprintf("Original (rho=%.1f)", rho_val)
  )
  box()

  image(
    seq_len(nrow(corr_rot)), seq_len(ncol(corr_rot)),
    corr_rot[nrow(corr_rot):1, ],
    col = cols, zlim = c(-1, 1), axes = FALSE,
    xlab = "Genes", ylab = "Genes",
    main = "Rotated"
  )
  box()

  plot(
    x, y,
    pch = 16, cex = 0.35,
    col = rgb(0, 0, 0, 0.18),
    xlab = "Original pairwise correlation",
    ylab = "Rotated pairwise correlation",
    main = "Pairwise correlation comparison"
  )
  abline(0, 1, col = "red", lwd = 2)
  mtext(sprintf("r = %.3f | mean abs diff = %.3f", r_xy, mad_xy), side = 3, line = 0.2, cex = 0.8)
}

par(mfrow = c(2, 3), mar = c(4, 4, 3, 1))

8 Interpretation Guide

When you read the report, the main differences to focus on are:

  • Type-I error calibration:
    • if permutation inflates type-I error as rho_set increases, it suggests correlation is not being respected by the null
    • rotation should remain closer to nominal alpha
  • p-value ECDFs:
    • departures from the diagonal under the null indicate miscalibration
  • Null ES histograms:
    • compare how the null distributions differ in spread/shape
  • Correlation-preservation plots:
    • points near the y = x line indicate rotated data preserve pairwise correlations well
